Your Claude API credits

If you already connected your math school on this Mac, that connection is reused automatically. You only need the steps below to connect a different account.

  1. Open Claude Console using the same email as your Max subscription. Complete the API organization setup if needed.
  2. In Claude Settings → Billing, link that organization under API credits. Check that the credits appear in Console Billing.
  3. Create a key in Console → API keys, then paste it below.

Use the organization receiving your included credits. This school cannot link subscriptions or add funds. Your Console billing settings control any charges beyond those credits.
