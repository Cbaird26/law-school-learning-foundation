This opens the course running on your own computer. If the page cannot be reached, start the launcher first.

First time on this computer?

  1. Download the course and unzip it.
  2. With Python 3 installed, open a terminal in that folder and run python3 launch.py. On macOS, you can also run Law School with Claude.command.
  3. Choose Claude settings or Connect Claude in the course. An existing ToE Math School API connection on that computer is reused. Otherwise, connect your own key from Claude Console.

The API key stays on your computer. Questions, lesson context, and photos you attach go to Anthropic. The public course does not provide shared API credits.

Progress is saved separately for the public and local addresses. Keep using the local address for your Claude study sessions. Your Claude Console billing settings govern usage.
