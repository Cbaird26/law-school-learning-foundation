Optional: run a local copy

The local option is for a computer with Python. On a phone, use the private tutor above.

  1. Download the course and unzip it.
  2. With Python 3 installed, open a terminal in that folder and run python3 launch.py. On macOS, you can also run Law School with Claude.command.
  3. Choose Claude settings or Connect Claude in the course. An existing ToE Math School API connection on that computer is reused. Otherwise, connect your own key from Claude Console.

The private hosted edition keeps the API key in a server-side secret. A local copy keeps its key on your computer. Questions, lesson context, and photos you attach go to Anthropic.

Progress is saved separately in each browser and for each course address. Keep using the private hosted address on your phone for Claude study sessions. Your Claude Console billing settings govern usage.
